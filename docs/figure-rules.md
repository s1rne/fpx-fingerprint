# Правило: схемы для статей

## Формат
1. **Размер текста на схемах: минимум 32px при ширине 2240px** (примерно 1.4% ширины).
   Заголовки 44px+, основной текст 34–38px, подписи 30px.
   Причина: Хабр жмёт схемы до ~700–900px в ленте, при этом мелкий текст <32px
   нечитаем. Если на схеме много текста, лучше укоротить текст, чем уменьшить шрифт.

## Компоновка
2. **Горизонтальный конвейер из 5+ блоков запрещён.** Каждый бокс получает
   ~260px ширины, текст рвётся на строки по 8 символов. Последовательности
   шагов рисуем вертикально: блок во всю ширину, номер, текст в одну строку.
3. **Ручные <br> в тексте запрещены.** Перенос должен случаться сам, для этого
   текст держим коротким. Если не влезает, сокращаем формулировку.
4. **Нет пустых зон.** Заполняем холст: либо сжимаем высоту под контент,
   либо добавляем содержательный блок (таблицу, вывод, вторую ветку схемы).
   Пустые поля сверху/снизу это потерянное место читателя.
3. **Схема читается без статьи.** Заголовок схемы должен нести утверждение,
   а не «Схема 1». Проверка: показываешь картинку отдельно, собеседник понял мысль.
4. **Один экран = одна мысль.** Если мыслей две, это два рисунка.

## Проверка перед публикацией
5. Рендерим, потом смотрим на схему в масштабе ~850px по ширине (как в ленте Хабра).
   Текст читается? Если нет, увеличиваем шрифт и перерендериваем.
6. Сверяем факты на схеме с текстом статьи и журналом находок.
